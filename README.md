# quote_spotbot
Сервис импортирует ваш плейлист из Spotify, находит тексты песен и позволяет экспортировать их в структурированный JSON-файл или продолжить общение с ИИ. Нейросеть проанализирует скрытый смысл, определит общий вайб треков , используя вашу музыку как контекст.

# Для установки всех модулей рекомендуем использовать 

```python
pip install -r requirements.txt
```
> [!WARNING]
> Возможно не работает т.к OpenRouter заблокировал пользователей из России. Используйте ВПН

# В данной программе можно :
- Экспортировать всю лирику в json формате
- Функция, где ии общается цитатами из ваших песен.
